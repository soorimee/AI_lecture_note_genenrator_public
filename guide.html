📖 수림 AI 서비스 이용 가이드

효율적인 학습을 위한 핵심 기능 및 사용 방법 안내

🔑 필수 사전 설정: Gemini API Key 연동

수림 AI는 Google의 대규모 언어 모델(LLM)인 Gemini API를 기반으로 구동됩니다. 원활한 서비스 이용을 위해서는 사용자 본인의 API Key 환경 세팅이 필요합니다.
Google AI Studio에서 무료로 API Key를 발급받은 후, 각 기능 페이지 상단의 입력란에 등록해 주세요.
* 입력하신 API Key는 서버로 전송되지 않으며, 사용자 브라우저의 로컬 스토리지에만 안전하게 저장됩니다.

1. 오디오 수업노트 생성

강의 음성 데이터를 텍스트로 변환하고, 핵심 내용을 구조화된 요약 노트로 자동 정리합니다.

  • ① 오디오 업로드: 분석할 강의 녹음 파일(.m4a, .mp3, .wav 등)을 업로드합니다.
  • ② 참고용 강의록 첨부 (선택): 해당 차시의 PDF 강의록을 함께 첨부하면, AI가 전문 의학 용어 및 영문 스펠링을 교차 검증하여 결과물의 정확도가 크게 향상됩니다. (강의록 용량이 클 경우 권장 X)
  • ③ 오디오 분할 및 분석: API 전송 용량 및 컨텍스트 한도를 고려하여 파일을 설정한 시간 단위로 분할합니다. 분할이 완료되면 [✨ AI 노트] 버튼을 클릭해 텍스트 변환을 시작합니다.
  • ③ 결과물 복사하기: 수업 노트가 완성되면 텍스트를 복사하여 [Notion] 앱에 붙여넣어 정리합니다.

2. AI 맞춤 퀴즈 출제

업로드한 강의록 문서를 기반으로 학습 목적에 맞는 모의고사 및 퀴즈를 출제합니다.

  • ① Source 파일 업로드: 시험 출제 범위에 해당하는 강의록(PDF)을 업로드합니다.
  • ② 출제 파라미터 설정: 난이도, 문제 스타일(객관식, OX, 증례형), 출제 문항 수를 지정합니다. 특히 '증례형'을 선택할 경우, 실제 임상 케이스(환자 정보, 주소, 현병력 등)를 모방한 실전형 문제가 생성됩니다.
  • ③ 데이터 추출 및 저장: 채점 완료 후, 생성된 전체 퀴즈 세트나 '오답 문항'만 별도의 JSON 데이터 파일로 로컬 환경에 다운로드할 수 있습니다.

3. 퀴즈 데이터 복습

저장해둔 퀴즈 데이터를 불러와 재학습 및 오답 분석을 진행하는 공간입니다.

  • ① 데이터 로드: 'AI 맞춤 퀴즈' 세션에서 다운로드했던 JSON 형식의 퀴즈/오답 데이터를 업로드합니다.
  • ② 반복 학습: 이전 기록에 구애받지 않고 문제를 다시 풀어보며 지식을 점검하고 해설을 복습할 수 있습니다.
